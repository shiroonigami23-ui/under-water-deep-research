# About and Methods

## Editorial approach

- **Every factual claim is footnoted.** Each article ends with its references, and the [All sources](/wiki/sources.html) page lists every source with the articles that cite it.
- **Primary sources first:** peer-reviewed papers, agency data (NOAA, GEBCO, IHO, UNEP-WCMC, IUCN, ISA) and expedition reports. Reputable science journalism is used for context and is labelled.
- **Contested science is flagged** in purple "debate" boxes, with both sides' strongest arguments.
- **Policy is described, not advocated.** Governance articles summarise each position as its proponents make it.
- **Dates matter:** each page shows when it was last reviewed, and the tracker records what changed.

## Catalog entries

Species and sea profiles are compiled from Wikipedia, FishBase, WoRMS, IUCN Red List assessments, NOAA Fisheries and peer-reviewed literature. Each entry links to its sources. Values such as depth ranges and lifespans vary between studies, so treat them as typical ranges and check the sources for precise work.

## Images

Catalog photos are real, openly licensed images loaded live from **Wikimedia Commons** (via Wikipedia). Each one links to its file page, which shows the photographer and licence. Where no open photo exists, the [Photo status](/wiki/photo-status.html) page lists the entry with a ready-made image-generation prompt and the file path to save it to. Images saved locally always take priority.

## Build

The site is generated by `scripts/build_site.py` from Markdown articles and JSON catalog data in `site_src/`, then served by GitHub Pages. Paper analyses are also exported to PDF. Everything is MIT-licensed. Corrections and additions are welcome as GitHub issues or pull requests.
