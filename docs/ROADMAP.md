- [x] New tracks: exploration, governance & mining, ocean change
- [ ] Data plots from open datasets (NOAA, OBIS, GEBCO bathymetry)

### Phase 3 — Interactivity

- [x] Interactive depth-profile explorer (`labs/dive-profile-lab.html`)
- [x] GitHub Pages hub homepage (`index.html`)
- [ ] Species map using OBIS occurrence data
- [ ] Mining-plume dispersion toy model lab

### Phase 4 — Output

- [ ] Compile a review-style paper / long-form article from the tracks
- [ ] Quarterly tracker digests

## 🔭 Long-term Vision

A clear, visual, well-sourced entry point to deep-ocean science — useful to students, writers and curious readers — that
stays current as new expeditions report back.

## How to help

Pick any unchecked item, open an issue to discuss the approach, then send a PR. Items in the earliest unfinished milestone are the highest priority.
